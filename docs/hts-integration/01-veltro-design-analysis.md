# 1. VELTRO HTS 화면 설계 분석서
작성일: 2026-11-19
분석 목적: 디자인/화면 흐름만 추출. VELTRO의 거래엔진·DB·API·인증 정보를 대상 HTS에 이전하지 않는다.

## 1) 분석 기준과 확인 범위
- 디자인 레퍼런스: [dlxodnjs2456-hash/veltro](https://github.com/dlxodnjs2456-hash/veltro)
- 실물로 열람한 파일: `index.html`(VELTRO WTS CSS/DOM), `desktop/patch/current.py`, `desktop/patch/login_v33.py`, `desktop/patch/updater_v39.py`, `desktop/patch/trade_runtime_v31.py`, `desktop/RELEASE`, `.github/workflows/build-veltro-hts-v112.yml`, Releases 목록.
- 제한: VELTRO Electron 원본은 `desktop/desktop_source.zip` 및 분할 base64/빌드 시 재구성 스크립트에 포함되어 있다. 이번 분석에서는 해당 ZIP 내부의 전체 `src/renderer.js`, `src/styles.css`를 직접 복원·시각 실행하지 않았다. 아래 정확한 그리드 치수·색상은 접근한 WTS `index.html` 기준이고, Electron 버전의 시각적 일치 여부는 별도 대조가 필요하다.

## 2) 디자인 토큰 — 확인한 WTS 원본
| 항목 | 확인한 값/원칙 |
|---|---|
| 브랜드 | `#1687d9`, `#38bdf8` |
| 상단/좌측 배경 | `#0b1e2d`, `#12344c` (좌측 탐색) |
| 작업 영역 배경 | `#eef2f6` |
| 패널 | 흰색 `#fff`, 경계선 `#d8dee7` |
| 기본/보조 텍스트 | `#111827`, `#667085` |
| 매수/매도 구분 | `#d84d48` (매수), `#2d66c9` (매도) |
| 숫자 | tabular-nums, 가독성 우선 |
| 글꼴 | Arial, 맑은 고딕 계열 (원본 WTS) |

이는 디자인 참고값이며 대상 프로젝트의 확정 브랜드·기존 손익 색상 규칙을 덮어쓰는 지시가 아니다.

## 3) 화면 정보구조
### 로그인
- WTS 소스: 어두운 배경, 중앙 로그인 카드, ID/비밀번호, 오류 메시지.
- Electron 패치: 전용 왼쪽 이미지/포스터, 버전 라벨, 사용자/잠금 아이콘, 이미지 로컬 대체 표시와 원격 이미지 캐싱을 다루는 코드가 확인됨(`current.py`, `login_v33.py`).
- 디자인 이식 대상: 이미지 구역과 로그인 폼의 비율, 정보 밀도, 오류/연결 상태 표시. 기존 로그인 API 및 사용자 정보는 이식 대상 아님.
- 원본에서 자동 로그인·ID 저장 옵션이 실제 존재하는지는 별도 검증이 필요함. 확인 전 신규로 넣지 않는다.

### 트레이딩 화면
- 상단: 약 50px 높이 헤더, 브랜드·서비스명, 우측 계정/잔고 요약.
- 좌측: WTS에서 약 210px 종목/메뉴 영역, 어두운 내비게이션과 종목 선택.
- 중앙: 시장명·현재가 상단 스트립, 탭(호가/포지션/미체결/체결/차트/종목정보), 차트/호가 작업 영역, 하단 거래 표.
- 우측: WTS에서 약 300px 주문 전용 패널. 매수/매도, 시장가/지정가, 수량·가격과 실행 흐름.
- 기준 WTS 그리드: `210px minmax(720px,1fr) 300px`; 중앙 내부 `minmax(440px,1fr) 280px`; 하단 약 220px. 수치는 원본 WTS의 화면 구조를 설명하며 대상 HTS에 고정값 복사하지 않는다.
- Electron HTS에는 독립 renderer/스타일 패치, 패키징된 Highcharts 자원, 로그인 포스터, 시세/차트 보조 UI의 흔적이 있음. 독립 다중 창을 원본 전체에서 확인한 것은 아님.

## 4) 차트·호가·주문 UI 참고
- WTS: 봉 주기 1/5/15/30/60분, 호가·차트·주문 패널 분리, 상단 현재가 강조.
- Electron 패치: 로컬 Highcharts 번들, 기술 지표, 시세 갱신 표시, 응답 대기 최적화 관련 코드가 확인됨(`current.py`, `trade_runtime_v31.py`).
- 가격 표시·체결 가능 여부는 디자인 대상이 아니므로 반드시 대상 시스템 API 판단을 사용.
- 해외선물/국내주식별 지원 기능 차이는 그대로 유지한다. 특히 대상에서 국내주식 호가창을 제거한 기존 정책을 원본 레퍼런스 때문에 되돌리지 않는다.

## 5) 업데이트 UX 참고
- `updater_v39.py`에서 `electron-updater`, `checkForUpdates`, GitHub provider, 다운로드 자동화, 업데이트 완료 시 '지금 재시작/나중에' 대화상자, 정상 종료 시 설치 옵션이 확인됨.
- `desktop/RELEASE` 값은 `1.0.55`. VELTRO GitHub Releases의 `v1.0.55`에는 `latest.yml`, `VELTRO_HTS_Setup.exe`, `.blockmap`이 게시됨.
- 원본의 실제 설치/자동 갱신을 실기기에서 검증한 것은 아니며, 대상 프로젝트에 해당 코드를 통째로 붙이면 안 된다.

## 6) 디자인 이식 전 필수 결정
1. 대상 브랜드 HFM KOREA와 기존 색상·손익 색상 규칙 유지.
2. 상단/좌측/차트/주문/하단의 *비율과 정보 계층*만 참고.
3. 대상의 Electron `WebContentsView` 분리 구조 안에서 독립 컴포넌트별 렌더링 계획 확정.
4. 작은 창에서 가격·버튼·탭이 잘리지 않도록 최소 크기 및 스크롤 정책 수립.
5. 디자인 변경 전/후 스크린샷 비교; 실제 거래 숫자/데이터는 절대로 디자인 목업으로 대체하지 않음.
